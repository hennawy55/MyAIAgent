# مساعد التذكيرات – MyAIAgent Pro

تطبيق Android محلي لاستقبال إشعارات بوت Telegram المحدد، وتحليل نصوص التذكير العربية، وإنشاء منبّهات على الهاتف.

## الخصائص

- واجهة عربية داكنة مبنية باستخدام Jetpack Compose.
- لا يحتاج إلى Backend أو Firebase أو API أو اشتراك.
- تخزين محلي للتذكيرات باستخدام Room.
- استقبال إشعارات Telegram عبر NotificationListenerService.
- فلترة الإشعارات حسب اسم البوت الذي يحدده المستخدم.
- تحليل صيغ عربية شائعة: اليوم، بكرة، بعد بكرة، أيام الأسبوع، التاريخ الرقمي، وصيغ الساعة 24 ساعة وصباحًا/مساءً.
- اختبار التحليل منفصل عن تسجيل المنبه.
- منع معالجة الرسالة نفسها أكثر من مرة.
- استعادة المنبّهات الداخلية بعد إعادة تشغيل الهاتف.
- إدارة وحذف التذكيرات من داخل التطبيق.

## المتطلبات

- Android 8.0 أو أحدث.
- صلاحية الوصول إلى الإشعارات.
- صلاحية المنبّهات الدقيقة على Android 12 أو أحدث.
- صلاحية إشعارات التطبيق على Android 13 أو أحدث.

## البناء

المشروع يستخدم:
- JDK 17
- Android Gradle Plugin 8.9.2
- Gradle 8.11.1
- Kotlin 2.0.21
- Android SDK 35

يمكن بناء APK عبر GitHub Actions بعد رفع المشروع إلى GitHub:
1. افتح تبويب Actions.
2. اختر Build Android APK.
3. شغّل Run workflow أو ادفع Commit جديدًا.
4. بعد نجاح البناء نزّل Artifact باسم MyAIAgentPro-debug-apk.
5. فك ضغط Artifact وثبّت app-debug.apk.

## إعداد التطبيق

1. افتح التطبيق واحفظ اسم البوت كما يظهر في عنوان إشعار Telegram.
2. فعّل الوصول إلى إشعارات التطبيق من إعدادات Android.
3. فعّل صلاحية المنبّهات الدقيقة.
4. اسمح بإشعارات التطبيق.
5. اترك إشعارات Telegram مفعّلة، ولا تضع المحادثة في وضع صامت إذا كان النظام يمنع ظهور إشعاراتها.

## الاختبار

- اكتب: `فكرني بكرة الساعة 8 مساءً`
- اضغط «حلّل الرسالة».
- راجع الموعد المعروض.
- اضغط «تسجيل المنبّه» فقط إذا كان الموعد صحيحًا.

كلمة «اختبار» وحدها يجب أن تعرض رسالة توضح عدم وجود وقت، ولا ينبغي أن تغلق التطبيق.

## حدود مهمة

- التحليل محلي وقائم على قواعد لغوية وصيغ تاريخ ووقت مدعومة، وليس نموذج ذكاء اصطناعي متصلًا بالإنترنت.
- التطبيق يقرأ محتوى الإشعارات التي يعرضها Android فقط؛ لا يستطيع قراءة سجل محادثة Telegram المخفي أو الرسائل التي لا يظهر لها إشعار.
- يجب أن يطابق اسم البوت عنوان الإشعار الذي يعرضه Telegram.
- في مواعيد اليوم يحاول التطبيق إرسال المنبّه إلى تطبيق الساعة. إذا منع Android ذلك، يستخدم منبّهًا داخليًا. راجع تطبيق الساعة عند ظهور رسالة تفيد بإرسال المنبّه إليه.
- بعض واجهات Android ومصنّعي الهواتف قد يقيّدون عمل التطبيقات في الخلفية؛ يجب اختبار استقبال إشعار فعلي على الهاتف بعد تثبيت النسخة.
- لا يمكن ضمان التشغيل على كل جهاز قبل اختبار APK على الجهاز المستهدف.

## ملاحظة ترقية النسخة

النسخة الجديدة تحتفظ بنفس applicationId (`com.example.myaiagent`) لكن APK debug المبني على GitHub قد يكون موقّعًا بمفتاح مختلف عن النسخة السابقة. إذا رفض Android التحديث، احذف النسخة القديمة ثم ثبّت الجديدة. حذف التطبيق القديم قد يمسح تذكيراته المحلية.
