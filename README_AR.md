# My AI Agent — مشروع Android أولي

## المتطلبات
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- جهاز Android 8.0 أو أحدث

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد `MyAIAgent` في Android Studio.
3. انتظر Gradle Sync.
4. شغّل التطبيق على الهاتف.
5. أدخل اسم البوت كما يظهر في عنوان إشعار Telegram واضغط حفظ.
6. افتح إعدادات الوصول للإشعارات وفعّل My AI Agent.
7. امنح التطبيق إذن الإشعارات.
8. فعّل صلاحية Alarms & reminders من الزر المخصص.

## أمثلة اختبار
- `فكرني بكرة الساعة 8 مساء`
- `ذكرني اليوم الساعة 18:30`
- `منبه يوم 25/11/2026 الساعة 9 صباحا`
- `موعد 2026-11-25 الساعة 20:15`

## السلوك
- مواعيد اليوم: يرسل التطبيق ACTION_SET_ALARM إلى تطبيق الساعة؛ تحقق يدويًا من ظهور المنبه.
- المواعيد المستقبلية: AlarmManager.setAlarmClock مع تخزين محلي وإعادة جدولة بعد إعادة التشغيل.
- استقبال الرسائل: إشعارات Telegram الرسمي فقط (`org.telegram.messenger`) مع مطابقة عنوان الإشعار لاسم البوت.
- لا يستخدم التطبيق Telegram API أو خادمًا أو قاعدة بيانات سحابية.

## قيود النسخة الأولية
- هذا Parser يعتمد قواعد محدودة وليس نموذج ذكاء اصطناعي عام.
- يجب أن يظهر نص الرسالة في الإشعار.
- اسم البوت يجب أن يطابق عنوان الإشعار.
- صيغة الساعة 1–12 دون صباحًا/مساءً تُرفض لتجنب التخمين.
- ACTION_SET_ALARM لا يحدد تاريخًا مستقبليًا؛ لذلك مواعيد اليوم فقط تذهب إلى الساعة الأصلية.
- صلاحية المنبهات الدقيقة قد تكون غير مفعّلة افتراضيًا على Android 14/15.
- يلزم اختبار سلوك البطارية والإشعارات على جهاز Motorola الفعلي قبل الاعتماد اليومي.

## ملاحظة
هذه نسخة Starter وليست إصدارًا نهائيًا مختبرًا. لا يوجد Gradle Wrapper مضمّن؛ Android Studio ينشئ/يستخدم بيئة Gradle المناسبة عند فتح المشروع.


## بناء APK مجانًا عبر GitHub Actions
1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد إليه.
2. افتح تبويب Actions في المستودع.
3. شغّل Workflow باسم Build Android APK من Run workflow.
4. بعد انتهاء العملية بنجاح، افتح صفحة التشغيل نفسها.
5. نزّل Artifact باسم `MyAIAgent-debug-apk` وفك ضغطه لتحصل على `app-debug.apk`.
هذه الطريقة لا تتطلب تثبيت Android Studio على الكمبيوتر، لكنها تتطلب حساب GitHub واتصال إنترنت، وتخضع لحصة GitHub Actions المجانية.
